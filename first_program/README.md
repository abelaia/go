# first_program

Маленькие консольные программы на Go, собранные в одно меню.

- **Угадай число** — программа загадывает число от 1 до 100 и подсказывает «больше» или «меньше»
- **Конвертер** — °C ↔ °F и километры в мили
- **Генератор паролей** — пароль нужной длины, по желанию с цифрами и спецсимволами

## Запуск

```bash
go run .
```
