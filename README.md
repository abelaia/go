# Go

Консольные программы на Go: от мини-игр до менеджера задач. Только стандартная библиотека, без сторонних зависимостей.

![Go](https://img.shields.io/badge/Go-1.27-00ADD8?logo=go&logoColor=white)
![stdlib only](https://img.shields.io/badge/dependencies-stdlib%20only-brightgreen)

## Проекты

| Проект | Что внутри | Что используется |
|---|---|---|
| [**first_program**](first_program) | Три программы в одном меню: «Угадай число», конвертер °C ↔ °F и км → мили, генератор паролей | `math/rand/v2`, `strconv`, функции с параметрами и возвратом, обработка ошибок ввода |
| [**todo**](todo) | Список задач в терминале: добавить, показать, отметить выполненной, удалить | структуры, слайсы, `bufio`, удаление из слайса через `append` |

## Запуск

Нужен [Go](https://go.dev/dl/) 1.27 или новее.

```bash
git clone https://github.com/abelaia/go.git
cd go/todo
go run .
```

Для другого проекта перейди в его папку, например `cd go/first_program`, и выполни `go run .`.

## Структура

```
go/
├── go.work          # объединяет проекты в одно рабочее пространство
├── first_program/   # меню с тремя мини-программами
└── todo/            # список задач
```

Каждый проект — отдельный Go-модуль со своим README.
